# happy-feed-journal

An app that records feed and food for babies, ai native and friendly. Enjoy baby growing up time.

## Tech stack

- [Next.js 15](https://nextjs.org/) (App Router) + React 19 + TypeScript
- Tailwind CSS for styling
- SQLite (via `better-sqlite3`) for local persistence — the database lives at `data/journal.db` (gitignored, auto-created on first run)

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) and log a feeding to start the journal.

## Scripts

| Command         | Description                              |
| --------------- | ---------------------------------------- |
| `npm run dev`   | Start the dev server on port 3000        |
| `npm run lint`  | Run ESLint                               |
| `npm run build` | Production build (also type-checks)      |
| `npm run start` | Run the production build                 |

## AI insights (optional)

The home page shows a feeding insight. By default it is generated locally (no
network/keys required). If you set `OPENAI_API_KEY` (and optionally
`OPENAI_MODEL`, default `gpt-4o-mini`), the insight is generated by OpenAI
instead, with an automatic fallback to the local message on any error.

## API

- `GET /api/entries` — list feeding entries
- `POST /api/entries` — create an entry (`baby_name` and `kind` required; `kind` ∈ `breast|bottle|solid|snack`)
- `DELETE /api/entries/:id` — delete an entry
- `GET /api/insights` — feeding stats + insight message
